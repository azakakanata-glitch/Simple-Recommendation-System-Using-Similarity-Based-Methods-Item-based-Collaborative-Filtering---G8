            How it works

            The heavy computation runs once at start-up; each recommendation request then takes only a few milliseconds.

            1. Offline

              Read the data

              Read ratings.csv and movies.csv; split 80/20 into train and test for evaluation.

            2. Offline

              Build the matrices

              Rating matrix R and indicator matrix M, stored as float32.

            3. Offline

              Compute similarity

              Cosine, Pearson or Jaccard between every pair of movies with one matrix multiplication.

            4. Offline

              Shrink and keep k neighbours

              Penalise pairs with few shared raters, keep the k most similar movies, save the cache.

            5. Online

              Score the movies

              The ranking score is the summed similarity to the movies already watched, plus a predicted rating.

            6. Online

              Return the Top-N list

              Drop watched movies and movies with too few ratings, and attach a reason to each recommendation.
